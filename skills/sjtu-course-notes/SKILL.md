# 交大课程笔记

先区分用户要求“整理课程”还是“仅建立/测试流程”。仅准备流程时，不启动课程下载、整段转写或正文生成。后续停止与范围调整优先。

## 工作流程

1. 读取 [本机工具说明](references/workflow.md)。通过当前提供的浏览器工具在 Edge 核实课程、节次、学校日期和视频时长；不要复用上一课的课程ID、录像ID或截图时间。未明确是哪一节时，先读当前页面，再仅询问必要信息。
2. 优先取得当前录像已有字幕（transcript/captions）、课件和讲义。平台自动概要只作线索；确认字幕属于当前视频，不能将课件或概要当成完整课堂记录。
3. 缺少字幕时，用已有本地工具下载一条合适的录像轨道，再本地语音识别（local ASR），保存带时间戳的原始草稿。中文学术内容默认 medium，优先 GPU，运行库或显存不足则 CPU。不为每节课重复安装工具。向外部识别服务上传需遵循当次授权。
4. 根据转写与课件建立框架，再在主题转折、例题题面及证明结束处选取少量清楚的板书截图。优先从原始录像提帧；无法取得录像时使用浏览器播放和截图。不能用画面抽查声称已核对完整音频。
5. 按 [四部分模板](assets/note-template.md) 整理：①大致课堂框架；②按框架展开的具体内容；③额外有用知识点；④本节课涉及的例题和证明。关键术语附同义英语，Python 示例添加详细易懂注释。非数学课程第④部分对应课堂案例、推导或论证，没有则如实说明。
6. 核对公式、符号、假设、例题数值、证明逻辑和图片位置。明确区分课堂内容、整理者补充、待核实内容；不补造原题、不把额外练习冒充课堂例题。证明写出条件、结论、逐步推导、关键依据、易错点和视频定位。
7. 用学校课程日期命名 `YYYY-MM-DD_课程_本节主题_课堂笔记.md`，附截图、转写和材料索引。遵循当次聊天的交付目录要求，不写入项目镜像的只读 `sources/`。

## 保存与完成

- 用户指定项目时，确认是 ChatGPT 云端项目还是本地目录。保存本地文件不等于添加云端项目来源，移动聊天也不等于上传资料。使用可用且获授权的产品工具；不能上传时明确本地保存与云端未添加的边界。
- 登录失效交用户正常扫码；不请求在聊天中粘贴 Cookie、密码或验证码，不显示已有凭据。
- 报告实际覆盖范围、未核实之处和可点击交付文件。安装成功、模型加载成功、GPU小样本测试成功不等于完整课程转写成功。
- 不修改系统代理、路由或记忆文件，不将测试课参数写成未来默认值。

## 工具

通用助手：`scripts/course_media.py`。`doctor` 仅检查本机；`videos`、`download`、`transcribe`、`frames` 分别完成各步骤。先看 `--help`，只执行用户当前要求的步骤。Edge 本地工具启动入口为 `scripts/start_tool.ps1`。路径配置、操作示例及验证边界见 `references/workflow.md`。
